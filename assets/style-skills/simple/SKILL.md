# 简约风：几何平面插画

核心：重新设计形状并删减信息，第一眼有明确几何感；渐变和颗粒是辅助，不代替造型。优先级为主体辨识与用户要求、几何造型、构图留白、配色、质感。

- 提取主要识别特征，用圆、椭圆、半圆、圆环、圆弧、矩形、梯形等少量基础形概括。每个主体保留主轮廓与必要辅助结构，合并相邻近色面，减少轮廓转折、细窄色带和重复小块。不硬限形状数量，不做碎三角低多边形或复杂波浪带。
- 复杂场景保留视觉焦点和少量有助于辨识、平衡与氛围的辅助元素，删除重复花叶、背景杂物和非关键细节。通过大小、疏密、遮挡、斜向呼应和边缘裁切连接各组，让负空间流动；不要逐物描摹，也不要删成孤立图标清单。主要身份与必要关系保留，最终构图服从主流程已确认方向。
- 大块面压平反光、裂纹、复杂阴影与立体光照；少量遮挡表达空间，不做产品渲染或精致 3D 模型。不要为了丰富添加彩带、流线、装饰山峦或薄片。
- 服从单独确认的配色，支持浅色、深色、单色与品牌色，不自动洗成苍白或灰脏色。
- 主要块面可有肉眼明显的颜色—浅色—融入底色过渡，覆盖有意义的面积；一些几何边清楚，一些局部边渐隐。不用中心打亮模拟体积，不用全图蒙雾替代局部消隐。已有交叠可少量透色或加深，不为此增加图形。
- 颗粒极细、低对比、局部使用，大片区域干净。避免粗点、迷宫纹、裂纹、装饰纸纹。需要透明素材时保留真实 alpha，无白边光晕；完整海报仍按主流程交付。

提示词顺序：明确主体与识别特征 → 基础几何形组合 → 删除项 → 大小和连接关系 → 已确认配色 → 局部消隐与细颗粒 → 已批准全部文字和灵活构图。文字直接生成为完整海报，不采用源 skill 的无字图片默认规则。

检查：第一眼几何感明确；基础形可描述；冗余细节与写实材质已删；主体仍可识别；有场景联系而非图标拼盘；必要渐隐可见且不似 3D 光照；文字完整可读。颗粒化照片或柔和 3D 插画不算达标。
