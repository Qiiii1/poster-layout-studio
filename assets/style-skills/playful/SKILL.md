# 趣味风（拼贴） · playful

这是整理后的海报视觉配方，不是独立制作流程。风格、配色、构图依次单独确认；案例检索、文字与画面整图生成、联网授权、输出检查及一次针对性修正均由主 SKILL.md 负责。无需原始源包、参考图或额外工具链。

## 视觉方法

以批准的真实图片为主体依据，建立一处与当前主题有明确关系的材料事件；不能用同一套通用档案碎片应付所有主题。先决定切边语言、叠放关系和统一处理，再落实图像。

材料有物理感：刀切或撕纸纤维边、明确叠压遮挡、大小层次，部分轮廓突破隐含边框。避免等距小照片格或幻灯片式图解。可以疏朗也可以密集，依据实际素材和文字决定，不强制十二碎片或重复主体凑数量。

采用一个贯穿碎片的色调/印刷处理；若刻意保留反差，说明对立关系并控制一致性。边缘、光影和叠层要相互协调，局部文字可叠压但需可读。默认不加黄旧、无关西方档案、虚假历史标签。生成的是原图指导的拼贴视觉，不声称输出像素是真实档案复刻。

仅用用户素材或获准且许可明确的外部资料；联网按主流程授权，不复制他人完整构图。不将新增生成物冒充实物展品。

## 整图提示词

Create one complete poster using the approved real source imagery as subject evidence. Translate the source material into a crafted cut-and-layer collage: visible knife or torn-fiber edges, purposeful overlap and occlusion, varied scale, selected silhouettes breaking implied frames. Decide a coherent material voice and one unifying reproduction treatment, or an explicit controlled tonal clash; do not default to sepia, generic Western archival imagery or a tidy slideshow grid. Preserve actual subjects and identity, do not invent collection members or false provenance. Derive a theme-specific visual connection from the actual brief. Use the separately approved palette and flexible composition; include every approved title and practical text string directly in the finished raster. Fragment density is adapted to the actual sources and readable copy, never a fixed dozen-item requirement. No manual SVG or code typography, watermark, fabricated archival text or unsupported extra objects.

## 检查项

- 素材主体有批准来源且保持辨识度
- 切边与叠压具有明确物理感
- 大小和遮挡关系有层级，不是等距图格
- 统一处理或明确受控反差使画面成为整体
- 批准文字完整可读，无伪造展品来源
