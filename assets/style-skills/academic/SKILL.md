# 学术风：数字科技重构

提炼自 digital-tech-stylizer。核心是改变主体形状的表达方式，而不是在完整照片上加滤镜。须检查实际源图，确定少数必须保留的识别锚点与内部空间关系，例如轮廓、透视、姿态、开口和层次；无源图时不声称已完成来源重绘。

## 三种处理路线

默认 ASCII 字符网屏：用清晰可辨的等宽单字符或标点（如 . : + x #）按受控网格和明暗密度重建指定主体形面；有序变化的实心圆点承接另一些高对比形面，少量实色剪影支撑结构。提示词明确哪些区域用字符、哪些用圆点。近看是真实单字符，缩略图仍认出主体；纯圆点或伪字形不称作 ASCII。字符是绘图标记，不是正文、代码或额外单词。

用户要求纯圆点，或字符明显妨碍辨识时，可用渐变网点：先简化为色块、剪影或渐变形面，再由有序圆点的密度与尺度表达光线、轮廓和空间，保留低密度呼吸区，不均匀盖满噪点。

线描网屏适合轮廓鲜明、细节丰富的主体：实色剪影、流动轮廓线和细密网屏构造形面，局部像素台阶、扫描线或错位断裂沿形体发生，不把所有细节像素化。三者是本大类内部处理方法，不另增风格类别或构图编号，不要求额外选择卡，除非用户偏好影响结果。

## 强度、颜色与空间

- 默认高强度二维重绘：保留识别锚点和必要透视，用剪影、实色面、负形与字符/网点重构；减少照片材质、连续立体阴影和自然景深。只有用户明确要求写实保留时才轻度增强。
- 服从单独确认的配色。一个主色系及其明暗覆盖多数形面，辅助色服务少数结构，第三点缀仅在需要时少量使用；明亮或深色均可，不固定蓝粉黄，不逐块随机换色。深色集中于开口、阴影或结构对比，高明度区域仍能辨认字符和圆点。
- 科技感来自密度转场、形体中的像素边、窄扫描线或少量数字切片；不要通用 HUD、电路板、二进制段落、无意义界面框或额外光晕。
- 保留主流程确认的主体数量、灵活构图和设计性叠压。字符图像与真实标题/实用信息区分清楚，正文用完整可读文字，不使用字符密度模拟实际文案。
