# 首次完整出图

本文件在选择完成后读取。目标是提高一次成稿概率，不增加草案生图、自动重生成或用户确认轮次。

## 风格规则的适用范围

下列强制重画、细节删减与固定数量的风格/限制项仅用于简约风。其余五种风格用自己的视觉规则和原有提示词方法，不额外叠加本文件中的稀疏纹理、平面化、几何化或删除摄影材质要求；中国风以包内 original.md 原版为准。仍在生成前核对完整文案、源图用途、已选配色与构图、事实和文化约束，不额外增加问题或生图。

## 所有风格共用的排版要求

读取 layout-catalog.md 的选定类别，用一两句明确主标题、信息区和素材的组织关系，并写入最终提示词。排版是已批准的任务参数，不属于可取消的风格限制。对角排版必须让文字位置参与对角动线；四角排版是四角各一个大字。保持位置、比例自由，不增加提问或生图次数。

## 活动信息区的组织（所有风格）

默认不用竖线将展期、开放时间、地点等信息隔成等宽三栏或类似表格式信息条。优先通过留白、对齐、字号层级与自然分组组织信息，按文案长度及已选排版调整，避免机械均分。将这一具体组织方式写入最终提示词，不取消用户选定的图文排版关系。仅用户明确要求时采用竖线信息栏。素材本身的画框、建筑结构、画轴边缘等竖线不受此规则限制，不将其误判为信息分隔线。

## 冒号标题的语义层级（所有风格）

标题含“：”或“:”时，先按含义判断主副关系，不因标点机械拆分。若冒号前为主题名称，后为活动类型或解释性描述（例如“红砖与天际：城市建筑影像展”），默认前段为大主标题、后段为较小副标题；副标题字号可参考主标题的40%–60%，按字数、画幅和可读性调整，传播语再低一级。前后同等重要或用户明确指定等大时，不强制缩小后段。

在生成提示词中分别标明完整标题及主、副标题的准确字符串、相对大小和层级；可分行，保留全部标题文字，不擅自删改含义。冒号可保留，若以分行替代其分隔作用则须不改变原意及用户对标点的明确要求。此规则适用于所有配方和语言，不被风格默认标题大小覆盖，也不新增常规确认轮次。

集中看图时一并核对：主副关系是否可辨、字号是否争抢、完整标题是否保留；无需增加一次看图或自动再次生图。

## 简约风生成前编译一份短设计说明

把当前批准内容整理为以下字段，消除矛盾后才调用生图；这只是文字准备，不是第二张图片。

1. **事实与文案**：每个语言版本独立列出全部准确字符串及角色：主办、主标题、副标题、传播语、日期、时间、地点、行动提示。只允许合适换行，不删字、缩写、替换日期或自添宣称。完整内容优先于装饰；不得因追求简洁省略必须信息。不同语言使用同一视觉逻辑，但按文字长度调整层级与留白，不强迫逐行同位置。
2. **源图角色**：明确照片是主题/结构/色彩依据还是必须原貌保留的对象，不默认为要保留的摄影底图。分别写本次不可变特征（少量）、允许归并的形状、必须重画的材质。未获许可不能牺牲真实展品身份或文化保护项。源图含排除项按 cultural-review.md 处理。
3. **风格落实**：从选中配方提取3–5项能在画面看见的正向操作，至少写造型、边缘/媒介、细节处理；不能只写风格名称或“高级、精致”。选中风格决定非保护图形的表达方式，来源决定题材和识别特征。不要混入其他风格全部规则。
4. **色彩角色**：列基底、主色、辅助、点缀与文字色，沿用原图主要冷暖关系；约略说明主辅面积，避免逐个百分比挤压风格表达。确认的绿色点缀不能成为整图主色，原图色相保留不意味着原图纹理也必须保留。无精确采样不伪称提色。
5. **画面与文字层级**：一个主要视觉关系；明确主标题、次级信息、正文的相对层级与可读对比。文案较长时先扩大信息区、减少非关键图形、自然换行，不靠极小字硬塞。构图遵循选中关系，不照搬草图坐标；允许设计性叠压，保护字形和关键细节。没有来源的图形不冒充真实藏品。
6. **针对性限制**：只列本次最容易发生的3–5个错误，与正向操作对应；禁止项不能取代具体造型指令。不堆整套负面词、不反复粘贴事实或源 skill。

## 简约风的特别约束

要求“用基础几何形重新设计场景”，而不是“保留照片再加简约排版”。先确定圆弧、矩形、椭圆或梯形如何概括实际主体，再删去不影响辨识的摄影材质；保持原图色彩不等于保留裂纹、岩壁斑驳、金属反光或体积光照。用干净平涂与局部消隐建立层次，细颗粒仅辅助。除非属于用户要求或受保护的实际内容，不将高密度矿物纹理、复杂真实阴影和照片表面直接带入。例：曲面展墙可转为少量宽圆弧色面，悬垂织物转为简洁半透明矩形，不把“敦煌”自动解释为铺满壁画纹理。

其余风格按自己的配方核心方法灵活处理，不以简约风标准检查。

## 提示词顺序与调用门槛

目标/画幅/所选视觉语言 → 主体的具体重画方法 → 图文层级与灵活构图 → 来源保留项 → 色彩角色 → 完整准确文案 → 少量针对性限制。开头明确生成全新完整海报，附图只是所声明角色的依据；原貌保留任务则明确例外。采用正面可执行动作，不用“照着照片但又完全不同”等矛盾指令。

内部逐项确认：文案完整；风格能由造型/媒介识别；源图角色清楚；无未经批准的删改；色彩与选项一致；文字区足够；没有冲突的摄影/插画要求或其他配方要求；文化限制可落实。没通过就修改文字说明，不先调用生图试错。无需向用户展示检查清单或增加选择。

活动文案直接随画面生成；logo内的原有文字随原件置入，不重新生成。旧源规则中的无字、透明独立层、后期排字或空白标题槽不适用。不要捏造预约链接、二维码、机构标识或水印；用户提供的logo是已有素材，默认使用，不受“禁止新增标识”限制。虚构信息仅按获准范围编写，普通设计测试在交付文字中披露。海报画面不自动添加“虚拟活动”“虚构活动”“虚构课程测试”“概念展览”“教学模拟活动”或 Fictional course test 等同类说明；即使资料内含此类测试说明，也不默认将其作为海报文案。用户明确要求展示时再纳入。若省略说明会造成真实机构发布、人物背书或活动真实性的具体误导，先调整相关内容或提出必要说明，不套用无条件省略。

## 实际检查与交付

每版只生成一次；出图后统一按 [集中验收](final-review.md)，批量程序处理尺寸和复验，每张最终图集中看一次。以已批准文案和所选配方/排版为依据，不再全文读取已有规则或拆分多轮检查。记录具体不足，不自动修正生图。仅交付PNG、实际尺寸及必要说明，不生成编辑器或代码排版。

## 画幅与验收

按 [比例规则](canvas-ratio.md) 将已批准的方向、宽:高及明确指定像素写入提示词。生成前核对工具能力，生成后校验实际文件；默认允许5%以内相对比例误差，方向正确就不因微小取整误差重生成或暂停交付。普通比例要求不等于零误差要求；只有用户明确提出精确比例时才用0%容差。

用 scripts/check_aspect.py 的 acceptable_ratio/accepted 判断，不用 exact_ratio 作为默认拒绝条件。明显超差或方向错误才每版最多重试一次；仍不符则说明，不拉伸、裁切或补边凑比例。实际尺寸如实报告，文案与文化验收仍独立执行。

## 用户logo原件置入（唯一合成例外）

用户提供的logo必须使用原件原样置入，不参与生图重绘或风格化；禁止改色、改字、重构、裁切、抠背景、滤镜、描边、变形或添加装饰。

1. 实际查看用户logo，记录原文件与哈希，将它从风格化素材中分离。它是成品中必须保留的原件，不是让模型学习并重画的参考。
2. 生成提示词只描述logo的预留位置、占用尺寸与保护空间，明确“不生成logo或占位假标志”。全部其他图文仍由生图工具完成，不以带logo参考图让模型近似复刻代替原件置入。
3. 生成后使用可用的原件置入/确定性合成能力，把原logo放入预留区域。此操作由本规则明确允许，仅限logo，不恢复整体手工排版或后期排字。原有logo文字也不能改为新排的文本。
4. 不改变标识内容。位图保留原像素和透明度，仅在必要时整体等比显示；SVG通过保持原始样式、字样与颜色的正常渲染用于PNG导出，不做图形重建。若环境缺少原字体而改变字样，不能用近似字体冒充原样置入。原件白底或透明边距保留，不自行抠除或裁掉。
5. 将置入结果作为最终成图验收对象，复核logo的完整性、颜色、文字与内部比例；只校验生图底稿不算完成。记录logo原件来源及放置操作，不能把生成的近似标志描述为精确应用。

无法置入原件时，明确当前限制，不把logo送回生图重画、不自行修改文件，也不悄悄省略。原件置入不改变主海报画幅，5%比例容差规则仍适用。

## 必需logo的出现保证

用户明确要求使用的logo是必需交付元素：每个适用语言/尺寸版本都必须原件原样、完整且清晰可见。未置入、被遮挡、出界或被模型替换时，不得判为交付完成。

- 生成前按原件长宽关系预留足够区域和保护空间，避免标题、主体与其他元素侵入。logo原件中白底/透明边距保留；选择可见的放置区域，不通过改色、抠图或加描边增强它。
- 完成生图后必须执行原件置入；不能把“不让模型生成logo”误解为最终海报也不需要logo。只展示原logo附件、在说明中提到它或提示词写了它，都不等于海报中已应用。
- 对每个适用版本分别核对最终PNG。记录 logo_required、logo_applied、logo_visible，以及原件路径/哈希、置入区域和最终文件。logo_applied来自实际原件置入操作，不能凭模型画得相似就设为true；logo_visible来自查看最终图，不能只凭坐标推定。
- 必需logo任一项不满足，先修正原件放置并重新检查；该修正仅限logo，不增加生图次数或重排其他内容。没有原件、原件不可读或环境不能可靠置入时，明确缺口并保持待处理，不静默省略或将不完整图作为合格成品。
