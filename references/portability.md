# 跨设备统一规范

流程版本 2026-10-12.4。随包 SKILL.md 与 workflow.md 管理统一顺序，question-format.md 管理统一交互；风格源 skill 仅提供本包内提炼的视觉方法，不接管流程。旧 README、历史案例标签、界面默认提示词不能覆盖上述规范。用户当前明确指令仍优先。

将整个 poster-layout-studio 文件夹复制或安装到目标设备的技能目录，不单独复制 SKILL.md。运行时以当前 skill 目录为根解析相对路径；输出写当前任务的可写目录，展示图片使用目标设备实际绝对路径。不得依赖原电脑 C:/Users/ALW 路径、全局风格 skill、源 Downloads 包、已生成海报或飞书登录。来源说明中的原包名称只作溯源，不是依赖。

所需能力：读取输入图片/文案；Python3执行本地纯文本案例检索；本地绘制灰度示意图；完整图片生成/编辑；联网搜索（授权时）；问题选择卡（界面支持时）。工具名称、安装位置与系统字体可随宿主变化，选择本机可用工具，不能假称某工具存在。缺少 Python 或绘图依赖时可用同等本地能力完成相同任务，不能凭空编造案例结果或略过草图。

缺少问题卡时告知并用同样的字母选项在聊天询问；缺少联网时说明并依据输入给出配色，保留确认；缺少图像生成或无法显示草图时报告具体缺失，保留已完成选择，不交付提示词冒充图片、不恢复手动排版。必需能力缺失导致无法继续时等待用户选择解决方式，不默默更改流程。

便携包包含 package-manifest.json 文件校验表；复制后应核对全部文件 SHA-256 以确保版本一致。版本与文件一致可固定规则，模型生成、图片内容和宿主界面仍可能有差异，不承诺像素、耗时或 token 完全相同。

首次跨 AI 部署或能力适配时读取 cross-ai.md；该协议统一行为与确认条件，具体工具名可适配。无自动 skill 加载的 AI，请上传完整包并明确要求从 SKILL.md 开始读取，不只粘贴一个文件。
