# 换电脑使用与参考材料

必须安装完整 `poster-layout-studio` 文件夹，包括 `SKILL.md`、assets、references、scripts；只复制入口文件会丢失规则、图像和编辑器。

| 依据 | 包内内容 | 换电脑的使用条件 |
| --- | --- | --- |
| 用户素材与文案 | 不预置私有原图 | 使用者在自己的任务中提供，由宿主检查事实与主体 |
| 优化六条风格 | 提示词、视觉处理与检查，20 张本地参考 | 文件夹完整即可查看，不需安装或登录原独立 skill |
| 构图和排版 | 9 类构图、27 张图、16 个 CSS 模板和比例适配 | 本地读取；Node/Python 用于推荐和构建编辑器 |
| 标签和案例 | 标签与 1,313 条案例名称/标签/行号快照 | 可离线检索标签，不能把索引当成案例原图 |
| 匹配案例原图 | 按需从 Feishu 读取，未批量打包 | 使用者自己的身份须能访问文档并具备所需读表/图片权限 |

推荐先依据内容与实际素材，结合视觉处理、本地图与构图参考，再检索相关案例并查看 2–3 张可访问原图。说明每个建议借鉴什么；风格名相同不等于图像已比较。没有飞书访问时用本地材料继续建议，明确未查看的案例，不声称完成在线案例检查。

本包不含作者账号、登录状态、媒体 token、下载链接或绝对电脑路径。在线读案例需 `lark-cli` 及使用者自己的授权；缺少它不影响本地风格、构图图、CSS 与 HTML 编辑。生成和语义审核需要宿主提供图片生成/查看能力，HTML 本身不调用模型。原 skill 原文和脚本未作为运行依赖或自动安装项。

编辑器含六种系统字体组合；不同系统会回退，不能承诺字形完全一致。工程中嵌入的导入字体可随工程转移，仍需检查授权与实际导出字形。

提问固定使用真实按钮；宿主需支持原生交互提问或可显示的 HTML 选择面板，见 [按钮提问规则](button-questions.md)。纯文字选项列表不算按钮界面。

Feishu 修改不会自动进入已安装版本。维护者重新导入、查看、验证并发布新版后，其他使用者更新完整包才获得新材料。在线图的名称/标签与快照不匹配时，取图脚本报告索引过期，不能静默使用错行。
