# 画幅、方向与像素校验

本任务首次处理画幅时读取本文件，后续沿用已读取规则与批准参数，不在确认、生成、验收时重复全文加载。比例始终按 **宽:高（W:H）**，不是长边:短边。

| 比例 W:H | 方向 | 精确尺寸示例（非默认分辨率） |
|---|---|---|
| 4:5 | 竖版 | 1600×2000 px |
| 5:4 | 横版 | 2000×1600 px |
| 3:2 | 横版 | 1800×1200 px |
| 2:3 | 竖版 | 1200×1800 px |
| 3:4 | 竖版 | 1500×2000 px |
| 4:3 | 横版 | 2000×1500 px |
| 16:9 | 横版 | 1920×1080 px |
| 9:16 | 竖版 | 1080×1920 px |
| 1:1 | 方形 | 1600×1600 px |

## 提取与优先级
- “横板/横版/横向/landscape”统一为横版；“竖板/竖版/纵向/portrait”统一为竖版。“左右排版”不表示横版，“上下排版”不表示竖版。
- 支持 4:5、4：5、4/5、宽高比4比5，以及明确标为尺寸的1600×2000等写法。数字须关联“输出、海报、成品、画幅、尺寸”等语境；日期、开放时间、原图尺寸、PDF页面尺寸不自动成为输出要求。
- 采用本次用户明确要求；其次采用资料中明确的交付规格；均未提供时才默认4:5竖版。历史选择、输入照片方向、风格配方默认值与灰度示意图尺寸不能覆盖目标画幅。
- 记录来源原文与位置，并规范化为 ratio_w、ratio_h、orientation、target_width_px/target_height_px（未指定则空）、source、status。不同语言或不同交付物分别记录，不擅自统一。
- W>H为横版，W<H为竖版，W=H为方形。约分不颠倒顺序：1800×1200 → 3:2横版。
- 同一有效要求中“横版4:5”、比例与指定像素不一致，或用户与资料的优先关系不明确时，在原有需求确认卡指出矛盾并询问；不擅自倒置成5:4。不因案例多数或图像工具限制改写需求。
- 只有方向、没有比例时，只确认该方向并提出同方向建议（横版3:2、竖版3:4），在原有需求卡中确认；不能把方向当作精确比例。
- A系列纸张按明确物理尺寸及方向记录；不得将A4声称为精确2:3或3:4。单位与DPI未知时不编造像素/印刷规格。

## 确认与生成
需求卡写“竖版，宽:高=4:5”（或相应值），有指定像素则同时写明。不增加独立比例选择轮次；已明确且无矛盾时不重复问。
最终提示词开头明确每张独立海报的方向、W:H与已批准像素尺寸；不是一张画布内横向拼放多张海报。布局、文字换行、留白随目标画幅适配；源图仅作素材参考。
先检查当前工具实际参数能力：有size/aspect_ratio参数时传入支持的值；只有提示词时明确写入，但不宣称能精确锁定像素。不可编造参数、默默切换工具、以重复生图试比例。

## 实际文件验收与合理容差

默认按使用效果验收比例，允许生成工具的像素取整误差。批量读取实际PNG宽高，使用 scripts/check_aspect.py；比例相对偏差为 abs(实际宽高比/目标宽高比 - 1) × 100%。

- **默认通过**：相对偏差不超过5%，且横竖方向符合目标；不因这类微小差异重新生图、裁切、补边、暂停交付或询问用户是否接受。近似方形也按同一容差判断。
- **精确要求**：只有用户明确提出“必须精确比例”“零误差”等要求时，才把容差设为0；普通“16:9横版”等描述使用默认容差。若用户指定其他容差，按该值检查。
- **像素要求**：明确指定的输出像素另行核对；没有指定时，不把建议尺寸作为硬性要求。通过比例检查不代表满足指定像素尺寸。
- **结果字段**：用 acceptable_ratio 判断比例是否通过，用 accepted 汇总比例与指定像素；exact_ratio 只记录是否数学上完全相等，不能因为它为false就拒绝默认容差内的图片。

例如1672×941用于16:9时，相对偏差约0.053%，默认通过。正常报告实际尺寸，可称“约16:9”，无需反复强调无实际影响的小误差。

默认运行：`python scripts/check_aspect.py poster.png --ratio 16:9`。
明确精确要求时：`python scripts/check_aspect.py poster.png --ratio 16:9 --tolerance-percent 0`。

## 明显偏差与有限重试

只有方向错误或比例超出本次容差，才按每个语言版本最多自动重生成一次处理；重试仍明显不符则说明实际差异并等待用户决定，不无限循环。生成前已知工具无法满足本次验收要求时，先说明实际限制。不能因为工具无法锁定每一个像素，就把默认可接受的取整误差当作不支持目标比例。

保留原始输出。不进行非等比拉伸，不裁切或补边凑比例。明确要求调整像素且原图比例精确匹配目标时，可等比缩放并记录；近似比例虽然可通过默认验收，也不能以等比缩放声称能同时得到精确的目标宽高。放大不意味着增加真实细节。

内部校验记录包含目标、实际尺寸、偏差、容差、方向及通过状态。容差内的结果不标记hold；仍需独立检查文案、视觉、文化问题。过程记录不作为默认交付物。
