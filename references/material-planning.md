# 素材、配色、联网元素与排版候选

## 抠图前的主体清单

选择 cutout 后，在抠图调用前按来源逐项展示计划：如“图 1：奔跑的马，保留尾巴；图 2：三个购物袋，排除周围人物的腿部”。说明各主体独立移动还是成组，预计图层数，以及排除的对象。询问：“计划抠出以上主体，还需要增加、减少或调整哪些内容？”等待明确确认或授权你决定。已经准确指定全部对象与排除项时可直接记录，无需重复。

`subjectRoster: {confirmed: true, items: ["图1的马（含尾巴）", "图2的三个购物袋"]}` 保存脱敏描述。不能用“选择了 Y2K”“选择抠图”或通用“继续”替代主体名单确认。新加入对象需要更新名单、来源审核、保护区域和排版筛选。

## HumanGate：是否联网补充元素

在任何补充元素搜索之前问：“是否需要联网查找与素材相关的元素？A. 只使用你提供的素材；B. 搜索并先展示候选，你确认后再加入；C. 由我选择并加入相关元素（明确授权）。”已明确的选择沿用。普通“继续”不代表同意联网。可与多图/主体选择一起询问，以减少轮次。

- `no`：本次只用用户素材，不发起补充元素搜索。
- `suggest`：检索公开、脱敏的主题词，展示相关性、来源和拟放置位置，确认具体元素后才能加入。
- `use`：用户明确授权你选择；说明最终选用了哪些元素及来源。新增主体仍需更新抠图名单与输入审核，不随意改变海报主题。
- `pending`：尚未作出选择，不能先搜索后补确认。

外部候选先作为参考，不把整张网页图片直接当作可用素材。核对来源、允许的复用方式和必要标注，优先用户提供的准确标识、官方资料或清楚允许使用的资源；不要杜撰出处、人物身份、文物意义或仿造品牌文字。具体外部元素经确认后也要经过输入/输出审核。联网核对文化出处与联网添加元素是不同的用途，说明需要的查询范围。

`webAugmentation: {choice: "suggest", elements: [{name: "确认的元素", url: "https://example.org/source", accepted: true}]}`。未接受元素不能进入生成提示词和最终图层。HTML 只记录选择；实际搜索由 Codex 在相应工具权限内执行。

## 从素材提出配色

取色只使用已审核的实际素材，兼顾重要主体的识别色、面积较大的颜色和小面积强调色。多图时参考所有确认用于本张海报的素材，不能只取第一张。忽略透明像素、无关私人背景和极小噪点。

可运行 `python3 scripts/sample_palette.py --image /absolute/approved.png --output /absolute/source-palette.json`（需要 Pillow），或在 HTML 中使用“从已审核素材提取配色”。此操作只分析像素，不改图或上传图片。

给出 2–3 个由素材推导且适合所选风格的方案，明确底色、主色、强调色、主标题/正文颜色及 HEX，并说明每个颜色来自哪处素材。风格的单/双色限制仍适用；确保缩略图里文字可读，正文所在的局部背景要实际检查，不能只比较纸面色。必要时增加中性深色/浅色文字并解释用途。用户明确指定的颜色优先；素材配色是建议，不能自动覆盖。

`sourcePalette: {colors: ["#274DA0", "#E4DDD1", "#CA573C"], source: "图1蓝色布面、图2暖白纸面"}` 记录取色依据。角色颜色继续使用 `promptPaper`、`ink`、`accent`、`textColor`。点击采用才修改；改变生成角色色只影响下一次提示词，现有像素不会自动换色。编辑器提供素材浅底/深底两种初稿，需人工适配风格的油墨数量。

## 3–4 个排版方案

保留 16 个内部模板；给本次用户呈现最多 4 个经过筛选的候选，通常 3–4 个。候选使用实际文案和所选画布，不再把全部模板当成同等适合的选项。

1. 识别实际素材中不能遮挡的区域：脸部、识别结构、文化关键细节和必要准确标识。记录 `protectedRegions`，使用相应图像内部的 0–1 坐标，而非模板灰块。例如 `{layer: "background", name: "器物关键纹样", x: .42, y: .28, w: .16, h: .22}`。透明主体的同类区域用 `subject-1` 等图层 ID。
2. 推荐器映射真实 cover/contain、图层位置和尺寸，排除与保护区域相交的文字槽。旧 `subjectZone` 仅为较保守的粗略备用；没有区域标注不能宣称“无遮挡”。
3. HTML 进一步使用实际文字、字体和画布测量溢出与文字相交；Codex 逐个查看候选实际组合，检查笔画遮挡、透明边缘、局部对比及艺术标题。初次推荐和用户主动重新筛选时，移除存在遮挡的方案。编辑器保留已推荐的模板 ID；用户移动元素、更换字体或切换比例后，只更新预览与调整提示，不自动删除候选。推荐列表、字体选择和素材随工程保存。
4. 候选不足 3 个时只提供实际可用数量，说明原因并调整图像构图、文字断行/分组或模板几何；不删必要信息、不重新填入冲突方案。尊重已选布局，修改前说明问题和可行替代。

底图生成后重新标注实际生成图的保护区域。切换画布、替换素材、移动/缩放底图、增加主体或修改文案后重新筛选。区域模型保守，不能替代视觉审核；不承诺像素级理解或所有字体都完全一致。

## 可移动底图

background 模式把完整处理图作为 `background` 独立图层。用户可通过“选择底图图层”或图层列表拖动、缩放、删除、恢复和撤销；它位于主体与文字后方。仅底图图层移动时文字保持原位。切换文字模板保留底图像素和位置。

`edits.background` 使用当前画布像素，保存 `left/top/width/height`；`backgroundRect` 可在 brief 中指定初始 750×1000 参考坐标。cover/contain 在底图图层的矩形内适配原图；画布外部分被裁切。纯底图 PNG 与合成 PNG 使用相同的位置、尺寸和裁切，移动露出的区域使用纸面色。缩放调整图层框，图像保持比例；改变适配或画布后检查画面和导出。
