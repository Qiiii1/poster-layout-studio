# 当前六类视觉路线

仅保留六个大类：简约风 simple、中国风 chinese、赛博风 cyber、趣味风 playful、复古风 retro、学术风 academic。六类均使用 assets/style-skills/ 内精简文字配方，详见 [本地映射](local-style-skills.md)；学术风使用新接入的 digital-tech-stylizer 核心方法，默认可辨的 ASCII 字符与半色调圆点重构。

以 styles.json 的现行路由为准。旧案例标签仅用于检索，不是独立风格化 skill。完整图文生成为最终 PNG；风格、配色与构图分开选择，构图仅展示代码绘制的灰色块草图。
