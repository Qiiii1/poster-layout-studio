# Source notes

- `assets/editor/vendor/layer-editor.js` and `.css` are unchanged copies of the installed `editable-design` runtime, under its included Apache-2.0 license. The shell and adapter are separate files.
- Layout geometry is a visual reconstruction of the user's attached `9aaac0055ccef2706c9d5484aeab23d1.jpg`, numbered by row. It does not contain original source CSS or embed the source image.
- Artwork recipe provenance is documented in `style-adapters.md`. Original source-skill files and their bundled example libraries are not included in this package.
- The 2026-10-04 Feishu import adds seven base tag dimensions, eighteen visual subtypes, and a case index of 1,318 tagged records. Source sheet IDs, row numbers, aliases and excluded annotation rows are retained in `tags.json` and `cases.json`. Case artwork, signed media download links, scores and personal identifiers are omitted.
- Expanded recipes are independent visual adapters described in `visual-recipes.md`. `source-registry.json` records source URLs, pinned Git commits and download status. Raw third-party instructions, scripts and examples remain in the workspace download folder; they are not executed or bundled. Recommendations distinguish case associations from authored design rules.
- On 2026-10-07, the user explicitly requested column C of the Feishu style sheet `Plpjbx` as local visual references and authorized the GitHub update. The package includes those 18 images, preserving their original bytes and visible source marks, mapped to all 21 visual recipes. Source cells, sheet revision, dimensions, hashes, observed features and adaptation limits are recorded in `style-references.json`; use guidance is in `style-image-references.md`. Internal download URLs, media tokens, auth records and the rest of the case images are not bundled. These reference artworks retain their original attribution and do not inherit the bundled runtime's software license.
