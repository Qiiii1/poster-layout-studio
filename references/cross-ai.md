# 跨 AI 能力适配

本包是一个 skill，SKILL.md 路由、workflow.md 定义顺序、question-format.md 管理交互；工具名可变，行为不变。用户新要求优先。首次换宿主或工具缺失时读本文件，无须每次加载。

- 文件/案例：相对当前 skill 根目录解析；执行内置 Python 检索或等价算法，不编造案例结果。
- 问题：多问题卡同轮分别选择；仅单问题卡时同轮发多个；无卡时说明并同轮聊天选项，仍等收齐答案。
- 草图：本地绘图并在聊天实际显示；不能显示时说明，保留已选项并解决呈现能力，不冒充已展示。
- 联网：授权后真实搜索，缺失时说明并依据输入；不以记忆冒充查证。
- 生图：使用可用图像生成工具，一版一次、文字整图生成；无能力时说明并停在该步骤，不恢复手动排版或交付提示词冒充图片。
- 时间：使用宿主可信时钟记录 timing.md 阶段区间；无精确用量接口不编造 Token。

同包可统一规则，不能保证不同模型输出、排序语义判断、界面计时或耗时完全一致。许可、来源与文件校验要求见 portability.md 和 provenance.md。

用户logo采用原件置入，属仅限logo的确定性合成例外。宿主缺少原样置入能力时说明限制，不退回模型重画，也不擅自省略；其他文案与画面仍按完整生图流程执行。
