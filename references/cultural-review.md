# 输入与输出的文化审核

这是由 Codex 阅读素材、文案和使用语境后作出的审核。HTML 只保存状态、提示修改后的复核需求和阻止已记录的未解决问题；几何检查、关键词和取色脚本不构成文化审核。

## 输入检查：在任何生图、抠图、联网检索或公开预览之前

逐张查看用户提供的图像及可读文字，区分主体、参考图和背景。检查以下具体证据：

- 不必要的私人信息：可读证件、联系方式、住址、账户、支付或访问二维码、私人聊天及内部资料。人像本身不自动判为敏感；不推断人物的族群、宗教、政治观点或其他敏感属性。
- 需要了解用途的文化元素：可辨认的宗教器物、仪式、服饰、历史文物、文字、地图、徽记和政治符号。出现这些元素不等于存在风险；先结合用户提供的出处、受众和用途判断。
- 具体风险：错误指认出处、混淆不同文化、拟造文字或地图、断章取义、歧视或贬损表达，以及把具有特定意义的对象错误拆解、倒置或装饰化。对认不出的物件说明不确定，不虚构来历。

只在实际发现会影响制作的问题时询问需要的语境或处理方式，例如：“这处器物是否要保留原形？是否有不能裁切或变色的部分？”已提供的用途和约束直接沿用，不增加通用的审批问卷。

### 隔离

1. 发现具体问题时，记录素材编号、问题类别、位置和待处理事项。审核摘要不重复原始个人数据。
2. 需要隔离的文件保存在项目私有 `quarantine/`，可运行：

   ```bash
   python3 scripts/quarantine_asset.py --source /absolute/flagged.png --directory /absolute/private-project/quarantine --reason privacy
   ```

   `reason` 也可为 `cultural-context` 或 `unverified-source`。脚本只复制指定原件和写入最小记录，目录权限 700、文件权限 600；保留原件，不承诺删除设备、备份或缓存中的所有副本。
3. 隔离原件不得进入 HTML、工程 JSON、公开缩略图、安装包、Git、搜索查询或外部生图输入。隔离记录也不进入这些交付物。
4. 使用用户确认的安全区域、脱敏副本或其他已通过审核的素材继续。要求用户提供脱敏副本，或使用已获授权的本地脱敏能力；不能通过把原始私人信息上传给生图服务来完成脱敏。处理后重新检查副本，再取色和生成。
5. 文化用途尚未明确时，仅暂缓争议元素的使用；确认保留方式、替换或排除后再继续。合法的文化题材不会因为出现宗教或政治元素而被整张自动排除。

输入总状态：`pending` 未完成；`reviewed` 已检查且本次使用的素材没有未解决问题；`hold` 有未解决问题。被排除或隔离的原件仍保留私有记录；可用素材的检查完成后才将输入总状态改为 `reviewed`。生成脚本拒绝嵌入标记为 `hold` 的工程。

## 输出检查：检查实际组合和实际 PNG

查看完整画布和缩略图，检查生成后的主体、装饰、艺术标题、普通文字和它们的相互关系：

- 原素材中的文化身份、文字和关键结构是否被错误改变；是否新生成了没有依据的文化、宗教、地图或徽记元素。
- 标题、图像的裁切与并置是否产生了用户没有提出的贬损、刻板印象、错误归属或误导性叙事。
- 输入时已隔离的信息是否重新出现；外部元素是否在确认范围内，来源与需要的标注是否保留。
- 文化关键特征是否被标题挡住、截断或变形；保护区域随底图移动和缩放后的实际位置是否正确。

在 `cultural-review.json` 的私有审核记录中保存本次检查的输入/输出文件 SHA-256、发现、处理和仍需用户确认的事项。对具体符号或出处不确定时，询问用户；如需联网核对，先获得联网选择并使用可信来源，不把私人素材上传用于反向搜索。

已确认具体问题时修改相应图层/文案或排除该元素，沿用现有一次自动修复上限；复核新的 PNG。解决不了时说明具体问题并保持 `hold`，不能把问题导出为最终成品。

`reviewed` 仅表示本次实际检查已完成，不代表对所有地区、受众或用途作出保证。修改文字、素材、裁切、图层位置、配色或画布后，旧输出记录不覆盖新版本。编辑器会将已审核输出转为 `pending`；需要再次由 Codex 查看当前结果。

## 工程状态与交付

工程里的 `culturalReview` 只含脱敏摘要：

```json
{
  "input": {"status": "reviewed", "findings": ["使用的两张素材已检查；私人二维码已从可用副本中移除。"]},
  "output": {"status": "pending", "findings": []}
}
```

不要默认填入“已通过”。旧工程缺字段时为 `pending`。HTML 本身无法自动理解符号，导入新图片也不会自动获得审核通过状态。输入 `hold` 阻止生成提示词，输入或输出 `hold` 阻止 PNG 导出；`pending` 的 PNG 属于用于复核的草稿。最终交付前必须完成实际输出审核，并给出结果和未解决事项。
