# 分阶段计时

用户要求统计时，在第一次处理前记录可信 UTC 起点；最终保存与检查结束记录终点。总用时包含用户等待与工具等待，不用模型推测时间。

按 reading（读取/文化检查）、research（案例/联网）、choices（推荐/绘制/发问）、generation（生图）、review（检查/保存）记录开始结束区间。等待用户：问题实际发送成功时开始，收到对应答案时结束；部分回答继续记录剩余等待。等待与工具运行可重叠。

推荐用 `scripts/timing.py --file <任务目录>/timing.json start <阶段>` / `end <阶段>`；总开始调用 `start total`，结束 `end total`，然后 `report`。waiting 可跨轮重复，脚本保留区间。并行生图使用一个外层 generation 区间，不相加各版耗时。

报告 total、各阶段时间区间并集、waiting 并集和 total减waiting 的非用户等待时长；并行阶段有重叠，各阶段不能直接相加。非用户等待仍包含图像服务等待，不称纯计算时间。未闭合区间或缺日志标明不完整，不补造数据。Token只报告工具/API实际返回值，否则写无法准确统计，不将输出截断估算或账户百分比当消耗。
